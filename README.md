## 📖 About

Thonny IDE is an open source Python development environment created by the Institute of Computer Science at the University of Tartu. It ships with a bundled Python interpreter, so new users can start writing and running code right after install without a separate Python setup. The editor offers line by line stepping, a variable inspector, expression evaluation, syntax highlighting, code completion, a shell and support for MicroPython devices such as the Raspberry Pi Pico.

If you came looking for a Thonny IDE download for Windows 10 or 11, this page lists the current system requirements, install steps and common troubleshooting fixes. The setup file is a standard Windows installer and installs per user by default, so elevated permissions are usually not required.

**Good for:** Python beginners · students learning to code · teachers running intro programming classes · hobbyists working with MicroPython boards · parents helping kids with first scripts · developers who want a lightweight editor for quick tests · Raspberry Pi Pico owners

## 🛠️ Troubleshooting

| Problem | Solution |
|---|---|
| Setup file blocked by SmartScreen | Click **More info**, then **Run anyway** |
| Installer closes right after launch | Reboot Windows and run the setup file again from the Downloads folder |
| App starts but the shell shows no Python | Reinstall and keep the bundled interpreter option checked during setup |
| Antivirus flags the setup file | Update your antivirus definitions and re-scan; if it persists, download the setup again from the link above |
| MicroPython board not detected | Install the USB serial driver for your board, then reconnect the cable |
| Fonts look blurry on high DPI | Enable display scaling compatibility in the shortcut properties |
| Editor opens slower than expected | Close other heavy applications and disable unused plugins |
